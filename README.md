# Faktor Sepunya: Lompat & Kutip

Permainan platformer Matematik dalam satu fail HTML. Mengandungi lima level, faktor sepunya, Portal Faktor, checkpoint, haiwan, duri, bonus nyawa, Kuasa Kombo, Buku Faktor dan Raja Faktor.

## Main secara lokal
Buka `index.html` dengan pelayar moden. Bunyi dan muzik akan mula selepas interaksi pemain disebabkan sekatan autoplay pelayar.

## Terbitkan menggunakan GitHub Pages
1. Upload `index.html` ke root repository.
2. Buka Settings → Pages.
3. Pilih Deploy from a branch, branch `main`, folder `/(root)`, kemudian Save.

## Kawalan
- Butang atas kanan: ☰ menu, ⏸ jeda/sambung, ↻ reset.
- Butang pada skrin: Kiri, Kanan, Lompat, Mula, Misi Seterusnya, Kuasa Kombo.
- Komputer: anak panah kiri/kanan, Space atau anak panah atas untuk lompat, P untuk jeda, F untuk Kuasa Kombo.
